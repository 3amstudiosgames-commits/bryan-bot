## How to use:
On slack search for Bryan Hodukavich and go to the Dms and just type /bryan-hodukavich-help to check out how to use and available commands. 

You can also download the file and change the weather API key (OpenWeather or weather another weather API) and change the Tokens.

## Bug/Problems:
- Not having API keys if downloaded
- Typed wrong the commands like /weather or /remind-me
- Bryan is not being hosted (Nest)

(when used in slack app/web no problems/bugs were found)  
## All commands:

available commands:   
/bryan-hodukavich-hi - Say hi!  
/bryan-hodukavich-weather - Get Weather and Temp  (ex: /weather command + city)  
/bryan-hodukavich-joke - Get a Joke   
/bryan-hodukavich-catfact - Get a cat fact  
/bryan-hodukavich-remind-me - Tell Bryan to remind you in 2 min to wash plates: (ex: /remind-me + 2 wash plates)
